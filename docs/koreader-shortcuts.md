# Opening PokePal in KOReader

These shortcuts are coming in the next release. In 1.0.8, use
**Tools > More tools > PokePal**.

Copy the plugin to `koreader/plugins/pokepal.koplugin` and restart KOReader.
The welcome offers **Open PokePal**, **Shortcut help** and **Later**. It
appears once. You can always open the game from **Tools > PokePal**.

To choose a gesture:

1. Open **Settings > Taps and gestures > Gesture manager**.
2. Choose the gesture you want to use.
3. Select **General > Open PokePal**.

To use a QuickMenu, add **Open PokePal** to that gesture's actions and turn
on **Show as QuickMenu**. Book and file-browser gestures are set separately.
PokePal doesn't assign or replace gestures for you.

If Gesture manager is missing, enable **Gestures** in Plugin management and
restart KOReader. Hold **PokePal** in Tools to read the shortcut help again.
