All 386 Pokémon from Kanto, Johto and Hoenn are now available in both editions, with ten animations each.

- Browse by region and use every evolution branch through Gen 3. New animations include Hop, Spin, Charge, Swing and Combo.
- Open PokePal directly from Tools in KOReader, with a one-time welcome and shortcut help. Open PokePal is also available for gestures and QuickMenu.
- Scrolling now counts towards reading rewards, eggs and expeditions. Reading pauses while the sleep screen, welcome or shortcut help is open.
- Fixed search, nickname and book-title dialogs appearing behind the game.
- Fixed the sleeping-partner image and touch controls after waking in landscape. Removed unnecessary game saves when automatic rest is off.
- Added the missing Dark-type journal filter.

Includes [PR #7](https://github.com/itsParassharma/Pokepal-for-Kindle/pull/7) and [PR #8](https://github.com/itsParassharma/Pokepal-for-Kindle/pull/8).
