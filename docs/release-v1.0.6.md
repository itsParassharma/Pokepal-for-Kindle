### KUAL

Needs a jailbroken touchscreen Kindle with KUAL installed. KOReader is not required.

1. Unzip **PokePal-v1.0.6-kual.zip**.
2. Copy `extensions` onto the Kindle drive, next to `documents`. Merge folders if asked.
3. Eject, then open **KUAL > PokePal > Play PokePal**.

### KOReader

1. Unzip **PokePal-v1.0.6-koreader.zip**.
2. Merge its `koreader` folder with the one on your Kindle.
3. Restart KOReader, then open **Tools > More tools > PokePal**.

Back up the `pokepal` folder before updating. If you use both editions, update both. Older builds cannot read saves with these new features.

Reading rewards are optional. Kindle tracking depends on the timing data saved with each book. [How tracking works](https://github.com/itsParassharma/Pokepal-for-Kindle/blob/v1.0.6/docs/reading-rewards.md).
