Pick any of the 160 Pokémon and switch from **Profile > Change companion**. Each keeps its XP, bond and nickname.

- Fixed oversized text and overflowing buttons in KOReader.
- Added journal search and favourites, book memories, trail choices and eight new badges.
- Optional auto-rest, a KOReader sleep screen, larger text and stronger contrast.
- Less startup waiting, fewer KUAL screen flashes and fewer unnecessary save writes.

Download the **KUAL** or **KOReader** ZIP below. Back up your saves and update both editions if you use both. Older builds cannot read the new saves.
