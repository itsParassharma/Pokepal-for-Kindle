# Next features

Version 1.0.7 adds companion switching, a choice of all 160 Pokémon, more companion features and a KOReader text-size fix. See the [release notes](release-v1.0.7.md).

PokePal is a pet game first. Home keeps the original care controls, two rows of stats, bond and XP. Reading rewards are an optional feature under More.

The finished-book journal is available under **More > Books together**. You confirm each entry, which records the title, partner and date locally.

Automatic book completion needs more work. KOReader exposes a book summary status, but the [Kindle read-state investigation](https://github.com/zevisvei/kindle-reading-dashboard/blob/main/docs/read-state-storage.md) found firmware-dependent storage and temporary event records. Reaching the last page alone should not award a completion bonus.
