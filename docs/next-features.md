# Next features

Version 1.0.6 adds eggs, six backgrounds, decorations, nicknames, backup controls and optional reading goals and expeditions.

PokePal is a pet game first. Home keeps the original care controls, two rows of stats, bond and XP. Reading rewards are an optional feature under More.

A finished-book journal is still an option for later. It could remember which books you finished with each partner, but it needs a reliable completion event or a manual confirmation.

Book completion needs more work. KOReader exposes a book summary status, but the [Kindle read-state investigation](https://github.com/zevisvei/kindle-reading-dashboard/blob/main/docs/read-state-storage.md) found firmware-dependent storage and temporary event records. Reaching the last page alone should not award a completion bonus.
