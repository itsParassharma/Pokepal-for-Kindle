PokePal now has a standalone KUAL download. Copy its `extensions` folder onto your Kindle and open **KUAL → PokePal → Play PokePal**. KOReader isn't needed for that edition.

This is a **preview release**. The native executable builds and desktop checks pass, but it still needs a physical Kindle test. The initial target is the 2021 Paperwhite in portrait orientation.

What's new:

- All 151 Kanto Pokemon, including Mew, plus the nine Johto starter forms.
- Choose discovered Pokemon from the journal. Each keeps its XP and bond.
- Trails find unseen Pokemon before repeating encounters.
- Types and action-pose previews in journal entries.
- Idle, sleep, walk and attack poses for all 160 species; eating poses for 33. Persian and Arcanine have still idle poses. Front-facing samples, up to four frames.
- Rewritten install instructions, help and game text.

Downloads:

- **kual-preview.zip**: standalone KUAL edition for ARMv7 touchscreen Kindles. No KOReader dependency; hardware compatibility is unverified.
- **koreader.zip**: KOReader plugin. Existing 0.1–0.3 saves still load.
- **corresponding-source.zip**: game, native host and exact runtime sources.
- **SHA256.txt**: checksums.

Back up your save before updating. The editions keep separate saves; the install guide explains how to copy progress between them. Keep `extensions/pokepal/data/` when updating KUAL.

Unofficial fan project. Sprite credits and licenses are included.
